# Fetech v0.5.0b1 — Beta development candidate

> **Unpublished Beta:** `0.5.0b1` is the assigned source and distribution identity. No tag,
> GitHub Release or package-index publication is created by this version assignment.

Fetech v0.5.0b1 begins contract stabilization after the frozen v0.4 capability-closure candidate.
It retains 13/13 categories and 155/155 registered implementation paths while adding:

- fail-closed, versioned public contract discovery across Python, REST, CLI and MCP;
- durable cancellation and one authoritative terminal lifecycle transition;
- bounded dual-graph context routing with exact-source verification;
- a checked-in 100-task context-efficiency harness with prompt-free reports and a commit-bound,
  blinded independent answer-correctness workflow;
- normalized public validation and failure catalogues;
- native and format-aware parser fuzz regressions, reproducible-build verification, and bounded
  local storage lifecycle controls; and
- an exact public-surface compatibility baseline plus representative pre-Beta migration fixtures.

## Evidence boundary

The v0.4.0a0 publication contract remains frozen at 10/14 gates. This Beta version does not relabel
or regenerate those candidate artifacts and does not satisfy the outstanding systemd attestation,
qualified legal approval, tag/GitHub Release, or package-publication gates.

The required-Linux OOXML/PDF and broader container-mutation fuzz campaign also remains deferred and
visible. Registered optional implementations still require their declared tools, model artifacts,
or configured providers at runtime; 155/155 registration is not proof that every optional engine is
installed in a particular environment.

The tracked `fetech-0.5.0b1-beta.spdx.json` and
`dependency-licenses-0.5.0b1-beta.md` files provide deterministic, hash-bound engineering evidence
for the exact universal lock and reviewed license catalog. They remain an unpublished snapshot:
separately installed tools and model artifacts are itemized but not included as Python packages,
and the report does not replace artifact-level notice review or qualified legal advice.

The benchmark harness, corpus, and blinded-review workflow are implemented, but the Beta does not
claim the final context acceptance gate until a clean current-commit provider run meets the
retrieval targets and a complete independent answer evaluation shows no more than a
two-percentage-point correctness drop.
